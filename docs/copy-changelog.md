Additional substantial changes:
- Public sample: sixteen historical topics → eight current sections, three-line verdict and four ranked checks. Fictional workplace/crossing scenario remains labelled; no verified capacity, rent or operating format is invented.
- Methodology: internal processing vocabulary → source scope, observation versus interpretation, unknowns, rental limitations and AI fallibility. No independent factual certification is implied.
- Pricing: explain Ready/account/PDF delivery and non-delivery help without delivery-time, lifetime-access or automatic-refund guarantees.
- Purchase review: configured price, one-off report and real consent/supply boundaries; no enabled Checkout or Live claims introduced.
- Optional sign-in email: same-browser instruction; security URL placeholders and one-hour/single-use behaviour preserved. Hosted template unchanged.
- v2 prompt: versioned British-English style added within the existing 4KB instruction bound. Evidence slots, seven model sections plus deterministic Appendix, schema/validation/model/rates remain identical. Historical versions are not regenerated.
- Blog: shared conversion CTA and actual modification timestamp revised; article substance, slugs, structured publication filtering and general-guidance limitations retained.
- Regression expectations now follow eight sections and updated copy. Actual TSX render fixtures also verify disabled purchase states and retained data/uncertainty disclosures.

Unchanged intentionally: approved policy/consent text, raw source observations, applied SQL, frozen customer/report fixtures, calculations, licences, attribution, payment status semantics and security configuration.

The featured price card now sends users to the existing property check, with a secondary sample link; it does not initiate payment. Mobile-menu supporting text matches the footer. Incomplete report messages use saved progress and next action rather than internal Ready vocabulary. Snapshot busy and rate-limit replies are distinct, retaining the same status and limits.
