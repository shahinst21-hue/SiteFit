New `NativeStatistic` schema 2 is a bounded native statistical representation within `lib/data`, not a second collection/scoring pipeline. It retains release/geography identities, variable/unit/universe/period, aggregation type, observed zero vs missing/suppressed/unavailable/not-applicable, income intervals, disclosure control/rounding and lineage. It does not authorize a source merely because a payload validates. Its real loader must still admit exact dataset schema, rights, coverage and geography. Existing v1 SourceIds, source outcomes, input contexts and ready readers are unchanged; source-specific integration extends their boundary as required by each step.

`PolygonGeometry` preserves GeoJSON rings and disconnected parts. TypeScript checks shape/finite coordinates/closure/bounds; service-only PostGIS checks topology/dimensions/SRID, without silent MakeValid. Native projected geometry operations remain EPSG:27700 for area; no degree-based allocation, centroid precision upgrade or default map fixture.

Baseline `tests/fixtures/data/phase8-baseline.json` pins normalized-byte hashes of applied migrations and legacy fixture/security scenarios. It complements actual hosted ready-graph fingerprints and existing replay tests; it does not replace them. New migrations extend behaviour without rewriting prior files or historical rows. No production/provider purchase, durable job/lease/cache/billing/reservation or final numeric scorer is introduced.

Native Census profiles use service-only `source_data.census_profiles` and narrow import/activate/lookup RPCs. Each immutable dataset manifest pins geography release, exact published headers, archive/normalised hashes and retrieval/reference dates. Profiles retain parallel value/missing-reason arrays in original category order; zero is an observed value and a source blank remains null. Complete frozen London OA coverage is required for activation; no hierarchy sum or cross-table reconciliation is inferred. Temporary national ZIPs are discarded after successful admission under the implemented storage policy. Income and BRES require their own native geography/quality admission; these Census rows do not imply their coverage or activate scoring.

Phase 8 private collection uses two bounded batches over existing owned source rows. Matched version-2 TfL/FSA spatial queries use the frozen OS building point while preserving canonical postal coordinates. Native NUMBAT reads require an explicit release-pinned reviewed station crosswalk and exact requested day; unreviewed station coverage remains unavailable. These boundaries do not themselves activate new customer report generation or final scoring.


Native Income/BRES comparison operands preserve exact London native member distributions and target-excluded membership, release/provenance/reference-period metadata, source intervals and explicit exclusions. Income may use the existing descriptive percentile boundary; BRES raw native counts remain unranked pending an admitted comparison basis. Neither produces suitability direction or commercial scoring. Owned evidence/projection attachment and catchment cohort admission remain pending.
Station enrichment uses separate retained walking-matrix and native NUMBAT payloads bound to the same owned station register. Reviewed exact station IDs/names/modes and frozen release determine targets, capped at eight; omitted IDs, truncation and unconfirmed entrances remain explicit. Routing retains requested/snapped points and seconds/metres without inferring accessibility guarantees. Native 2025 TWT entry/exit profiles retain missingness and source provenance; they never become customers or pedestrian footfall. Failures remain per station, and historical replay uses stored outcomes. Database lineage guards independently verify parent bindings and native profiles.

PropertyData historical subsets bind the selected frozen UPRN, OS point/release and exact components, including secondary unit. Provider classification is not consent; unqualified area/EPC/domestic council tax cannot become admitted commercial facts. Point rivers/sea does not imply surface-water or overall premises clearance. Restaurants rent remains a native unadmitted candidate with unknown vintage, dispersion, radius units and format comparability; salon usage is not applicable. Retained source payloads exclude address display text, raw responses, personal fields and photos. Current caching and dated historical retention are distinct; reopening never refetches these outcomes.

Evidence schema 2 retains positional origin precision separately from statistical unit/code/release/method/estimate status, source checksum/operand paths, parent snapshot checksums, the complete frozen release vector and explicit missing state. The private builder verifies owned source/parent/geometry/property bindings and content digests. Census totals are dated area-allocated estimates; place counts remain native taxonomy records; matrix results remain modelled routes with unconfirmed entrances. Rent stays separate for later Economics. Schema 1 readers and claim validation remain strict. New report persistence and projection wiring are not activated by this private contract alone.
