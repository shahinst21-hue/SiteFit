# Minimum evidence admission before paid reporting

A Ready state proves stored/validated structure, not sufficient location evidence. New Checkout now requires at least one usable source-backed observation in the owned Snapshot. Completely missing observations cannot start a payment, reservation or contract; observed zero and explicitly qualified partial findings remain admissible. The Snapshot displays the reason when purchasing is withheld.

Before any Full AI intent, a new edition must contain a substantive reason linked to an admitted catalog fact in a decision section. Generic questions, unsupported prose and actions alone cannot become a successfully delivered paid analysis. The worker retains its existing intervention behavior on failure. Existing immutable Ready editions still reopen without regeneration.

This is an empty-evidence floor, not a new score, calibration, quality percentage or guarantee that every partial report has equal commercial value. Existing qualified observations, missingness, evidence validity, source attribution and limitations remain mandatory. No threshold for profitability or lease clearance is introduced.

Targeted regressions exercise actual Checkout denial before Stripe/reservation/contract work, observed-zero admission, unsupported/absent fact references, user-facing explanation and Full generation refusal before checkpoint/provider/freeze. Existing interruption, narrative-validation, export and replay tests remain active. Full synthetic generation fixtures now provide explicit source facts for their previously unsupported synthetic reasons; export checks still reject undefined text.

No source/AI/payment call or budget increase is needed to implement or test this control. Production installation and actual deployed verification remain separate release receipts.
